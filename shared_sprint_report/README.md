# Shared Sprint Report

`latest_report.pdf` in this folder is generated automatically every hour
(and any time someone clicks "Run workflow" on the **Sprint Report** GitHub
Action) - see `.github/workflows/sprint-report.yml`.

**If you're a teammate and just want to see the current sprint status:**
you don't need Python, a GitHub token, or any setup at all. Just open
`latest_report.pdf` in this folder on GitHub (or `git pull` if you have the
repo cloned) - it's always up to date with the real board.
